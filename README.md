# Custom 2D Game Engine - Pure C++ (From Scratch)

This is a personal **C++** project for practicing and learning core C++ concepts while building a lightweight 2D game engine from the ground up.

The main goal is to learn modern C++ and, at the same time, create a simple engine capable of making small arcade-style games.

### 🎯 Project Objective
- Strengthen fundamental C++ knowledge
- Build a functional 2D engine step by step
- Be able to create small playable arcade games using my own code

### ✅ What I Have Implemented So Far (April 2026)
- Sprite rendering
- Basic player controller
- Entity Component System (ECS)
- Math utilities (vector math)
- Basic collision system:
  - AABB Tree
  - Broadphase
  - NSquare collision detection
- Base Actor class for all engine objects

### 🛠 Dependencies & Technologies
- **Language:** C++20
- **SDL3** v3.2.16
- **SDL3_image** v3.2.4
- **SDL3_TTF** v3.2.2
- **RapidJSON** → [Repository](https://github.com/Tencent/rapidjson)
- **IDE:** Rider or Visual Studio 2022
